# 牙冠工作台流程与主视图集成

2026-10-10。本轮参照桌面 `WelooAI_1_0_UP3D_UI_Redesign_Plan.md` 和 `AICAD-CN.mp4` 的操作流程。云甲动态工作台匿名访问跳转登录，未宣称检查登录后的全部控件。界面使用本项目品牌，移除首页宣传性标题。

## 当前操作

1. **上传扫描与订单**：导入 3Shape ZIP 或分别上传上下颌；选择天然基牙/种植基台，打开上下颌 32 牙位图选择 FDI，保存草稿。已有设计可重新打开。文件卡显示源文件、面数和拓扑摘要；FDI 选择不等于已确认几何实例。
2. **牙位与边缘线**：确认目标基牙，人工 ROI/已有分区或上传独立 Prep；生成边缘候选、描点、拖点、撤销/重做后保存确认。插入轴建议须明确确认。已确认曲线为绿色，未保存曲线为琥珀色。可聚焦目标基牙。
3. **参数与牙库**：填写材料标签、扫描覆盖和人工位姿确认，确认加工轴数、粘接间隙、工程最小厚度与 AutoFit 目标间隙。专业冠形库、现有 STL 和需审核的裁切候选沿用现有接口。旧配置非零边缘间隙/延伸或自动整体补厚需明确关闭，不能静默改值。
4. **生成与微调**：生成模板初稿；确认局部坐标、真实邻牙面区及静态咬合变换后运行 AutoFit。原冠、候选和线框叠加进入同一个查看器；受阻或待审候选不能采纳。移动/旋转/缩放、加材/减材/平滑/局部移动在右侧内嵌面板操作，每次有效修改保存修订。
5. **检查与导出**：运行已有 W3 三维内冠构建和工程审核；查看邻牙、静态咬合及壁厚色图与 mm 图例，检查 QC，下载工程 STL 或工程包。距离色图与有符号穿透报告分开解释；顶点厚度色图最小值与含面心的完整采样报告不混用。

## 本轮实现边界

- 工作台只使用一个 Canvas；同病例步骤、候选及编辑工具切换不重建它。更换病例重新初始化场景。
- 步骤顺序显示 01–05，保留现有 API 面板 ID；草稿无需先确认 Profile 才能进入 Margin 步骤。
- 导航、生成和工程导出按服务端 `next_actions`、`confirmed_revisions`、产物有效状态及本地未保存修改共同控制。
- 未保存 Margin/Axis、未确认参数阻断下游操作；保存后仍需服务端确认。生成/编辑请求只显示实际请求状态，没有虚构百分比或阶段进度。
- AutoFit 的选择、静态变换、诊断裁取面和候选预览已接入主场景；缺少输入资格的自动适配按钮禁用，服务端继续独立校验。
- 右侧工具随步骤切换，编辑时集中显示 CAD 工具；侧栏可折叠，底部保留当前主操作和具体阻断原因。
- 此轮未修改几何算法、病例库、生产放行规则，也未添加依赖。

## 1.0 粗稿设计流程（后续更新）

- 虚线牙弓支持三维移动和旋转，拖动后回写位置；点击编号使用该位置作为定位种子，可再次点扫描修正。
- 新增 draft-preparation：在种子沿牙弓方向下方3mm截取单牙闭环，准备64点粗边缘与ROI预备体。只接受包含种子的局部闭环；已有边缘或冠体不自动覆盖。不是解剖Margin检测。
- 点击下一步采用当前粗边缘与方向，不要求先选择自动检测、轴求解算法。手工修线、轴及分割工具保留在高级折叠区。
- 默认工程配置间隙0.06、厚度0.8、5轴计算策略（并非材料或加工推荐）。相对咬合位置仍人工核实，不虚构自动配准。
- 优先当前FDI模板，缺少时尝试本地候选/可解析牙库。不自动全局批准模板。初稿生成后进入微调。
- 编辑支持等比例、三方向比例、位移、旋转、加减材和平滑；快捷键1/2/3移动/旋转/缩放，A/R/S/D塑形，Shift减材，Ctrl+Shift平滑，Ctrl+Z/Y撤销重做。操作参照exocad官方Freeforming；非宣称完整兼容3Shape快捷键。
- 验证：4组Node检查、6项后端针对性检查通过；隔离合成病例实际准备粗边缘、采用方向、生成、编辑、撤销、布尔内冠和STL导出入口跑通。FDI46本地牙库加载验证通过。
- 尚未验证真实患者粗截面和定位鲁棒性、自动接触求解与动态咬合。本轮粗边缘是固定深度截面，遇到无闭环需重新定位或手修；生产放行状态未改变。
