## 2. 第二层：历史病例离线回放（部分落地）

这是本项目**唯一**具备完整输入 + 真值输出的病例，见 `DATASET.md` §3.2。

当前断言（完整清单见 `ACCEPTANCE.md` §4）：

| 维度 | 断言 | 实测 |
|---|---|---|

| Boolean | 往返偏差 ≤ 0.02 mm | **0.0** |
| 就位方向 | 与基台拟合壁轴一致 ≤ 8° | **6.14°** |

🔴 三项挂在 `baseline.known_defects`，用 `xfail(strict=True)` 标记，修好后必须转正。

**合成几何的精度验收**（`test_insertion_axis.py`，24 项）：真值可构造，
因此精度断言放在这里。就位方向在无倒凹圆台上轴误差 **0.000°**，
刚性等变 **0.0000°**，分辨率 40/120/360 段之间 **0.0000°**。

**参数回归**（`test_parameter_regression.py`，21 项）：解析结果必须等于导入的
exocad 真值；未知必须保持 `None`；歧义零值必须阻断。

### 尚未建立

| 维度 | 为什么没有 |
|---|---|
| Chamfer / Hausdorff 对齐真值冠 | 只有 1 例有语义化 STL，无法做统计 |
| Margin deviation（预测颈缘 vs 真值颈缘） | 真值颈缘已可提取（见 `GT_MARGIN.md`），但患者侧 Margin 算法仍不可靠（`boundary_loops` 在真实扫描上产出退化环） |
| 邻接区距离 / 咬合距离 | 缺邻牙分割；咬合变换真值仅 1 例 |
| 技师二次编辑量 | 无技师在环记录 |
| 批量回放（15 例） | 12 例 STL 无角色标签、2 例无 STL、59 个 DCM 无法解码 |

**fixture 缺陷已修复**：真值颈缘改为从真值冠提取的 intaglio ↔ exterior 真实交界缝
（`app/geometry/gt_margin.py`）。旧的"最低 0.4 mm 带"只覆盖 16/24 方位角（残弧）。
新真值：闭环、简单、自交 0、方位角覆盖 1.000、spacing_cv 0.127、置信度 0.99。
详见 `GT_MARGIN.md`。

**但度量定义随之改变**：`baseline.json` 的 `metric_versions` 记录版本，
旧值在 `legacy_measurement`，**跨版本比较无效**。

### 推荐指标（在有真值后）

| 维度 | 指标 |
|---|---|
| Margin | 预测冠缘 ↔ Margin 曲线距离、Hausdorff、最大边界误差 |
| 形态 | Chamfer / Hausdorff / normal / curvature |
| 邻接 | 接触区面积、穿透深度、间隙 |
| 咬合 | 对颌距离、穿透量、接触分布 |
| 内腔 | spacer 偏差、就位可达性、undercut |
| 厚度 | 全局最小厚度 + 薄区面积 |
| Mesh | watertight / 非流形 / 自交 / 法线 |
| 人工 | 技师盲评、无需修改率、修改时间 |

**验收原则**：不建议只追求"与技师 mesh 的 Chamfer 距离"。
牙冠是受约束修复体，边缘、就位、邻接、咬合、厚度和制造性应成为**一级指标**。

## 3. 第三层：盲评（未启动）

需要外部条件，当前无法开展：

- 至少 3 名技师/医生
- 同一批病例的人工 CAD 结果（需可授权使用）
- 商业 CAD proposal（需授权）
- 受控的数据流转与去标识化（见 `DATASET.md` §5）

**盲评的重点不是表面几何，而是"需要多少修改后才可生产"。**
这一层是唯一能判断"是否有真实生产价值"的验证，不能靠几何指标替代。
