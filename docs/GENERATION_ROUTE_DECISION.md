## 三、确定性 CAD 主线的五段链（主路线）

1. **统一病例输入契约**：工作颌 / 预备体 / Margin / FDI / 牙轴 / 邻牙 / 对颌，全部使用明确坐标系；
   沿用本轮已验证的元数据变换链（`modelInfo.Margin ↔ constructionInfo.Margin` Kabsch，
   残差中位 0.011mm；不依赖 GT、不做无约束 ICP）。
2. **模板匹配与定位**：按 FDI/尺寸/形态从牙库选模板（炼金王主线，牙颈环来自标签环），
   用 Margin 曲线 + 牙轴做**约束配准**，禁止无约束全局 ICP 破坏颈缘定位。
3. **外形约束形变**：局部控制点/笼式形变调整冠宽/冠高/邻接面/咬合面；
   Margin 为强约束，邻牙与对颌为几何约束（对应 H.2.x/K0/J.3 线，J.3 的"可行域"口径优先）。
4. **内冠与间隙**：按预备体 + CementGap 构造内表面，处理就位方向与颈缘过渡，
   避免简单偏移导致自交/壁厚异常（替换已被证伪的体素列 blockout）。
5. **Contact Gate 与自动质检**：**先排除牙龈/牙间乳头与无效邻接区**（P0-4 的判据：
   该冠点的最近颌面点是否在牙面），再查接触间隙/穿透/咬合干涉/颈缘误差/水密/自交/体积；
   保留失败原因而不是只输出一个布尔。
