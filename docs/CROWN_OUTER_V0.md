## 实现中的两个实测教训（都进了代码文档与测试）

1. **LᵀL 正规方程不可用于本问题的边界约束**。第一版用
   `min ||LV′−LV||² + λ·约束`（双调和能量），数学上收敛（残差 1e-8、
   目标函数更小），几何上却是灾难：边界动 1.5~3mm，自由内部被拖出
   11~20mm、39% 面翻转。双调和能量没有极大值原理，且边界顶点的 delta 行
   会把"边界与邻居的微分关系"也当强约束。改为经典 **Sorkine 行替换法**
   （`LV′=δ`，边界行替换为恒等，咬合区弱锚行走 lsqr）后：
   0% 翻转、内部位移衰减正常（median 0.07mm）。
2. **输出选面必须只排除根部触碰面**。按"冠部 mask"选面会把颈环所在的面
   全部丢掉，切口悬在半空（148 条边界边不在颈环上）。正确规则：
   只排除触碰根部的面，颈环顶点留在输出里，底边 = 患者颈缘。

## 口径钉死：``flipped_face_ratio`` 的定义

调试期间出现过"0% 翻转"与"0.13% 翻转"两个读数——前者是在**错误的输出面
集合**（不含颈环圈的冠部面）上算的，已废弃。**正式口径**（18 例批量共用，
定义写在 `quality.mesh_quality` 的 docstring）：

> 在生成器实际写出的输出面片集合（冠部+颈环）上，逐面比较「变形后法向」与
> 「摆位后模板（同面、同顶点序）的法向」，点积 < 0 记为翻转。参考系取摆位后
> 模板而非原始模板——摆位是刚体+均匀缩放、不产生翻转。

第一颗病例的正式数字是 **0.13%**。

### 与均匀缩放的相关（系统性来源确认）

| 指标 | 与 scale 的相关系数 |
|---|---:|
| signed_overall median | **+0.60** |
| Chamfer | **+0.58** |
| signed_occlusal median | +0.54 |

margin 周长大的病例（scale 1.06~1.13）整体被撑胖、周长小的（0.90~0.99）
偏瘦 —— **冠体丰满度不应随 margin 周长均匀缩放**，而均匀缩放正是 v0 的
摆位设计（§7）。真实技师冠的轮廓由咬合与邻接决定，不由预备体大小决定。

### 结论（对应方案 §11 的评价注意）

误差结构完全符合"v0 缺什么"的预期，**没有一项指向 Margin Deformation**：

* 颈部准（p95 0.02mm）、无明显翻面、咬合解剖保持 —— Laplacian v0.1 够用，
  **ARAP 不触发**；
* 近中 −0.41 / 颊侧 +0.61 的系统性不对称 = **邻接接触缺失**（技师冠向邻牙
  鼓出）→ 下一步 **Contact Engine**（v1）；
* 咬合面 +0.78 且与 scale 相关 = **对颌约束缺失** → v2 **Occlusion Engine**；
* 均匀缩放带来的整体胖瘦漂移 = 摆位阶段的已知限制，等 v1/v2 的真实约束
  到位后再评估是否需要各向异性摆位。
