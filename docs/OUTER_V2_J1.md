# J.1 —— Intaglio-Constrained Crown Outer（外表面被内表面 + 最小厚度包络约束）

**状态**：引擎与单测已落地；**真实例上未达标，且原因已被量化**（见 §5）。
下一提交要做的不是调参，而是把包络从"逐点投影"换成**水平集（等距面）**。

用户 2026-10-02 规格：输入 = Intaglio + FDI anatomy + Cervical loop + MinThickness
field；输出 = Outer；核心约束六条：① 共享颈缘边界 ② Outer 包住 Intaglio
③ 局部厚度 ≥ T ④ 解剖偏差尽量小 ⑤ 无翻面 ⑥ 无自交。

---

## 1. 为什么不做 `Outer = Intaglio + normal·T`

牙尖/窝沟/邻接/颈缘都是凹面：法向 offset 会自交，而且凹面处的"局部法向"本身
不可靠（Occlusion 留下的翻面会让它直接说谎）。所以改用**距离场包络**：

```
Envelope = { x : s(x) < T(x) }    s = 到 Intaglio 的**带符号**距离（材料侧为正）
约束     : 任何 Outer 点都必须落在 Envelope 之外，即 s(p) ≥ T(p)
```

即"内表面外面套一层最小材料厚度保护壳"。它是**隐式定义**（距离场水平集），
**构造上不可能自交**。

**必须用带符号距离**：外表面若整片落进预备体内部（真实例的覆盖率失败），最近距离
照样很大（= 到内表面的距离），只有符号能区分"在外侧太近"与"根本在预备体里面"。
（第一版只用最近距离 → 真实例 4147 个违反顶点里相当一部分被漏判。）

## 2. 为什么必须**双向**测（本模块最贵的一课）

顶点级约束**兜不住面内部**：粗三角形的三个顶点都 ≥T，它中间仍可能离内表面更近
（合成例实测 0.42 vs 要求 0.50）。而**验收口径是内表面侧的 t_closest**
（Thickness Audit 从内表面采样点测距）。所以每次迭代两个方向都做：

```
(a) 顶点侧：Outer 顶点 → 内表面距离 < T  → 推到 cp + dir·(T+safety)
(b) 内表面侧（**验收口径**）：Intaglio 采样点 → Outer 距离 < T
        → 对该点**局部球内所有可动顶点**给目标（球内顶点全 ≥T ⇒ 整块面 ≥T，
          因为球是凸的 —— 这是"面级保证"的来源）
```

球半径 = T + safety + 工作边长；**球内已经 ≥T 的顶点不动**（否则会把远处顶点
朝轴心方向推，实测 deficit 反而从 0.586 涨到 0.702）。

## 3. 工程要点（都踩过）

| 要点 | 说明 |
|---|---|
| 工作副本**保形细分** | 几何不变，把"任意面内点到最近顶点"的距离上界压到 ≤0.35mm |
| 径向推 vs 法向推 | 法向投影 `cp + n̂·T` 在**凸棱**上是不动点（棱上法向被平滑成斜的，实际只给到 T·cosθ）→ 卡死；改径向推到 \|v−cp\|=T，光顺面与棱角都恰好 T。仅当 v 落在预备体**内部**（s<0）时才用法向穿出去 |
| 颈环 | 永不作 seed（`movable` 里排除）；映射内表面点时也必须排除 —— 第一版把 44 个内表面点映到颈环顶点，共享颈缘边界当场失守 |
| 内表面侧排除带 | 用与 Audit 同值的 `intaglio_exclude_mm=0.6`：颈缘处两面**按构造**重合、壁厚必然→0，在那里强制 T 等于跟"共享边界"打架（第一版只用 0.1 → 卡在 z=0 环上 deficit 恒 0.5002） |
| 接受判据用**总违规量** | 用 max 会被单个病态顶点钉死（每个 α 都被拒、一步都走不了）；max 仍需如实上报 |
| 翻面门用**面积加权** | 大面翻向 = 折叠（必须 0）；数值级微面翻向不是折叠。计数口径下真实例 α=0.0625 仅 1 个微面翻向就被拒 → 一步都走不了。`max_flip_ratio=None`（关计数门）+ `max_flipped_area_ratio=1e-4` |
| 测距对象必须**随位形更新** | 第一版 `SurfaceQuery` 建一次就不管了 → 永远在跟**初始** anatomy 比距离 → 所有 α 都"未下降"（假 CONFLICT）。新增 `SurfaceQuery.update_vertices`（拓扑不变只挪点，向量化重算 + 边界重采样） |

## 4. 顺带修好的两个 Thickness 侧缺陷（本次才发现）

1. **`refine_max_edge` 的分裂组合把一组子三角形绕反**（`(0,1,1)` 那组）：面积照样
   守恒（面积守卫看不出来）、但 37.6% 的子面翻向、顶点法向被抵消成切向
   → 所有依赖"平滑法向"的量（Thickness 的 `outside_by_face_normal`）都被污染。
   已修 + **新增绕向守卫**（平面细分下面积加权法向和逐位守恒，破坏即抛错）。
2. **`SurfaceQuery` 的采样树**在查询点落到网格**内部**时可能整行候选都是"无关联面
   的顶点样本" → 兜底到质心 kNN（新增 `dead` 分支）。

## 5. 真实例结果（cf_b1b73bae221211b1，H.1 + 代型 intaglio）

| 项 | 值 |
|---|---|
| 输入（H.1）违反 | 外顶点侧 4147 点、内表面侧 2901 点；max deficit **1.66mm**；总违规 2311mm（= 覆盖失败的量级） |
| 一轮全步投影（α=1） | **面积翻面 18.5% + 自交 1350 对** → 被硬安全门拒绝 |
| α=0.5 | 面积翻面 5.7% + 自交 314 → 拒绝 |
| 引擎实际行为 | 只在 α≈0.03~0.06 上小步推进：6 轮 142s，能量 2311→2108（**−9%**），max 1.66→1.35 |
| 解剖偏差（已动部分） | 位移 max 0.31mm / p95 0.084 / 中位 0.020mm（63% 顶点动过） |

**结论（这是本次最有价值的产出）**：真实例要补的厚度是 **1.66mm 量级、覆盖约 40%
的表面** —— 这已经**不是"投影修正"而是"重新造型"**。逐点投影在这么大的位移下必然
把网格折起来（18.5% 面积），所以线搜索只能取极小 α，收敛慢到不可用。
**正确解法是把包络建成水平集（等距面）再整体投影**：等距面按定义不自交，
位移场是全局一致的，能一次给出大幅、无折叠的修正。合成例也印证了这条分界：
**局部薄（单区域）**的病例，引擎能一轮收敛到位（1056→0 违反，颈环精确 0）。
