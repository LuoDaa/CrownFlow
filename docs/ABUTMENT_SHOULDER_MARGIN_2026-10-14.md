# 已有修复基台：非平面肩线集成

算法版本：`welooai/abutment-shoulder/1.0`。

## 已接入

- `geometry/abutment_margin.py`：已验证绿色外缘算法的项目实现。20°凸特征候选、128 个角区、整圈动态规划、两侧剖面和连续性/贴面检查；保持非平面肩线与原始模型坐标。
- `POST /api/designs/{id}/draft-preparation`：已有修复基台确认后直接生成肩线候选，替代原固定 3 mm 截面。组件初次定位阶段仍不把扫描杆自动视为修复基台。
- `POST /api/designs/{id}/margin/detect`：已有修复基台使用同一肩线算法，确认轴后重新检测不会切回旧 M1。
- 原有纠偏点、局部替换、移动、平滑和确认会话继续使用。修复纠偏点索引与重复写入问题；无效编辑在成为新候选前被拒绝，保留此前有效曲线。
- 前端“已有修复基台（非扫描杆）”选择明确表达修复角色，自动检测发送相应声明；生成后的人工确认流程保持不变。

未清空病例、覆盖已有人工边缘或改动原始测试数据。新的提取仍是待人工核对候选，不自动作生产放行。

## 验证

针对基台的 14 项测试通过，包含三例实际接口首次提取/确认轴/重新检测/确认保存、无肩台反例、刚体坐标保持、纠偏点唯一性与完整编辑会话。测试使用隔离数据库。

三例首次提取与用户确认过的绿色参考逐点一致；确认轴后重新检测的双向曲线最大差异小于 0.03 mm。参考仅代表这三例用户确认的目标位置，不代表独立临床计量真值。

前端 `npm run build` 通过。运行中的 8010 服务已重启；`192.168.110.17:8757` 现有端口转发指向该服务。两地址已验证返回新前端资源 `index-3jWQb425.js`。

## 使用

1. 打开 `http://192.168.110.17:8757`，刷新页面。
2. 导入上下颌，选择牙位与“已有修复基台（非扫描杆）”，创建草稿。
3. 在基台冠终止线页点击自动检测；系统分离候选并生成起伏肩线。
4. 旋转核对并按需微调，确认保存后继续插入轴和牙冠设计。

无清晰外突肩部、特征缺失或跳跃时返回人工处理提示，不回退到固定平面线。当前验证覆盖三个清晰肩部病例；圆角或其他复杂形态需要另行验证。

已有人工保存或下游设计时，首次定位接口仍保留原覆盖保护。确认轴后的检测只建立候选会话，只有用户确认才生成正式边缘修订。
