# WelooAI 1.0 操作流程与实现状态

更新日期：2026-10-11。适用范围：本地单冠工程设计工作台。

## 操作顺序

| 页面 | 用户操作 | 当前系统处理与完成条件 |
|---|---|---|
| 首页：导入病例 | 输入病例名，一次上传上颌和下颌 STL/DCM；或选择 3Shape 订单 ZIP。也可打开已有病例。 | 创建病例、校验并保存扫描，解析订单中可用的信息。导入完成后进入牙位页，不再次要求上传同一批扫描。 |
| 01 选择牙位 | 在 FDI 牙位图选择目标牙位，核对左侧扫描中的实际位置，选择天然牙冠或种植基台冠。 | 保存牙位对应的设计草稿。订单预填牙位仅作提示；已有设计可直接继续。 |
| 02 确认边缘线 | 点击目标预备体咬合面中央获取粗边缘候选；旋转模型，从颊、舌、近中、远中逐面修正，人工复核后保存。候选不适用时沿真实颈缘手动描绘。 | 提取局部预备体模型，生成待复核的截面粗线。只有有效闭环经人工复核并保存后才能进入方向页。 |
| 03 就位方向 | 查看蓝色箭头和倒凹参考，拖动方向手柄；需要时展开数值输入，确认方向。 | 将人工确认的方向记录为设计修订。确认后进入参数页。 |
| 04 设计参数 | 检查间隙、最小厚度、咬合位置、冠形来源、适配目标及加工设置，确认当前参数。 | 保存参数版本并检查当前支持项。 |
| 05 生成牙冠 | 核对生成资格及所需邻牙、咬合输入，生成候选；查看形态、质量指标、构建检查，再明确采纳或退回。需要时进入冠体微调。 | 使用模板初始化冠形，并对具备可信输入的阶段运行邻接或静态咬合适配；保存候选和阶段结果。 |
| 06 检查导出 | 构建内冠，检查壁厚、接触、静态咬合、边缘和间隙；导出当前有效的工程 STL。 | 运行布尔、间隙、倒凹处理和工程 QC。最终文件供工程复核，不表示临床或制造放行。 |

首页完成导入后，工作台从“选择牙位”开始。工作台右侧一次显示一个任务；顶端步骤可回看已满足条件的页面。上传入口留在首页，牙位页只显示病例与上下颌是否已导入。缺少目标牙所在颌扫描时，应返回首页重新导入完整病例。3Shape ZIP 在导入时先预览，再确认建立病例。

## 边缘线的具体操作

1. 在牙位页选定 FDI 和修复类型，点击“下一步：定位预备体”。进入边缘页后，在目标预备体的咬合面中央点击一次。系统基于该点及局部表面法向提取预备体，并尝试给出 **64 点的完整粗边缘候选**。点错基牙时，未确认的候选可通过“重新选择基牙”替换；点击“取消定位”可恢复原候选。
2. 放大并旋转扫描，从四面判断黄色线是否贴合真实颈缘。可拖动控制点，或先选点再点击正确位置；撤销、重做可用于修正。显示的一整圈线只是待复核候选。
3. 如果粗线无法修正，选择“手动重画整圈”，沿真实颈缘按顺序在预备体表面点选**至少 12 个有效位置**。描绘期间是开放折线，不代表边缘已闭合。点击“生成完整闭环”后，服务端拒绝范围过小、交叉、明显只在牙体一侧或未围住定位中心的点列；通过后以样条插值并投影到预备体表面，生成 64 点候选，仍须逐面修正。“取消重画”或 Esc 可恢复开始重画前的候选。
4. 勾选四面检查确认，再点击“确认边缘并继续”。少于 12 点、重复或无效点、未人工复核的闭环不能在当前工作台确认。历史病例中的三点三角形可读取，但服务端拒绝重新保存或采纳；应重新描绘。

自动候选采用定位点下方约 3 mm 的扫描截面；它**不是**可靠的解剖颈缘自动识别。点数和闭环形状也不能证明医学准确性。扫描缺损、复杂预备体、局部模型含邻牙或牙龈时，可能需要可信的独立预备体 STL 和人工修线。

边缘保存后，在独立的“就位方向”页确认蓝色箭头。初始方向来自定位点附近的表面法向，只是可调整的起点；不能据此推断最优插入路径。左键旋转相机、右键平移、滚轮缩放，F 适应模型，1–5 切换标准视图。旋转视图不会改变扫描网格及边缘点的原始坐标。

## 生成、微调与导出

自动适配按服务端资格运行。邻接适配需要可信的局部方向、真实邻牙面区和目标间隙；单侧缺牙须明确标记，未知邻牙不能视为缺牙。静态咬合适配需要两颌扫描、已确认的来源与刚体位姿及目标间隙。仅满足一类输入时，只执行该类阶段；没有可执行适配时，可明确选择仅生成模板初稿，其邻接和咬合仍为未评估。种植基台冠保留模板候选和人工复核路径。

候选可与适配前外形比较，查看现有距离色图、质量指标和构建检查。生成候选不覆盖已采纳冠体；冲突、部分完成或未验证候选不得采纳。采纳前再次核对输入摘要、设计版本与候选文件；退回保留原冠体。只有当前有效的已采纳冠体才能进入微调。

微调支持移动、旋转、等比例及各方向缩放、局部加减材料、平滑和局部移动。每次完成编辑保存外形。完成后重新构建内冠并运行工程检查。边缘、方向、参数、邻牙、位姿或冠体发生变更时，旧最终 STL/QC 不再作为当前有效结果提供下载。

## 当前能力边界

已实现首页扫描或订单包导入、FDI 手动选牙位、局部预备体提取、截面粗边缘候选、手动种子点插值、边缘和方向分别确认、参数修订、模板与适配候选、候选审核、三维微调、内冠构建、工程检查和工程 STL 导出。

尚未证明可靠自动 FDI 识别、可靠解剖 Margin 识别、自动邻牙实例分割、自动上下颌咬合配准、动态咬合和制造级精度。3Shape CE 加密 DCM 需要合法解密密钥或原软件导出的 STL。复杂真实扫描仍需人工检查及可信输入；工程结果不得直接作为临床或制造放行依据。
