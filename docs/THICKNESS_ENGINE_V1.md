## 1. 输入链路（有几何证据，不假设坐标系）

```
.modelInfo ──┬─ Margin（MODEL 坐标系）──┐
             ├─ ConstructionFile: -46-modeldie.stl（sha 77e0fc85…）
             └─ 设计参数 MinThickness=0.6 / CementGapThickness=0.08 / …
                    │
                    ├─ 代型 STL（ModelPlatelessDie，V=11157/F=22310）
                    │      ↓ Kabsch（两套 margin 同一曲线，环移 1 点，RMSD 0.0166mm）
                    │   代型对齐到设计坐标系：margin→代型 p95=0.018mm
                    │      ↓ 以 margin 折线为界切"预备体表面"（轴向偏移 s>−0.02mm 的连通分量）
                    │   prep.stl（8355 顶点 / 16063 面 / 206.3mm²）
                    └─ intaglio = prep + CementGapThickness(0.08) 沿代型外法向偏移
```

* 代型选取：`.modelInfo` 的 `<ConstructionFile>` 里 `PartType=Model*Die` 且
  `Filename` 含 `-<fdi>-` 的那条 → 用 **SHA256 内容对账**（不写原文件名/路径）。
  本病例的索引字段 `modeldie_asset_id == final_crown_asset_id`（同一个哈希），
  **再次印证 AutoMargin 审计的根因：索引里的"代型"经常就是修复体壳**，不能信。
* **对齐只用设计输入**（两套 margin 点列），不用 GT；
* 验收用同帧校验（audit-only）：GT 冠内表面 → 代型 **p50=0.095mm**（设计
  `CementGapThickness=0.08`）—— 证明"intaglio = 代型 + cement gap"这一物理模型。

工具：`tools/stage_prep_case.py`（服务器，纯 stdlib，PHI-free 输出 `die_ref.json`）、
`tools/align_prep_to_design.py`（本地，Kabsch + 切分 + 写 `prep.stl` / `prep_meta.json`）。

## 3. 两个厚度测量 + 内外判定（本节是本次最花时间的地方）

| 量 | 定义 | 用途 |
|---|---|---|
| `t_closest` | 到外表面的**最近距离**（与法向无关） | 保守账 |
| `t_ray` | 沿内表面外法向的 **Möller–Trumbore 首个交点**距离 | 主判定（"真正的壁"） |
| `w`（绕数） | 广义绕数判断内/外 | **替代"最近面法向"判内外** |

结构不变量：`t_ray ≥ t_closest` **必然成立**（射线命中点本身就在表面上）——
实测 8301 点全部满足，这条同时是实现的健全性检查。

`AMBIGUOUS_THICKNESS`：两者差 > `max(0.15, 0.3·t_closest)`。实测咬合区 46%
触发；触发点的 `|n̂·dir_to_closest|` 中位 **0.513**（非触发点 0.871）——
即"最近点落在另一个特征上"（牙尖侧壁/窝沟），这正是用户要的语义。

### 为什么内外判定必须用绕数

Occlusion 的 2.08% 翻面 + 自交会让"最近面法向"在折叠区**系统性说谎**：

| 判据 | 判"在冠外" | 说明 |
|---|---|---|
| 最近面（平滑）法向 | 811 | 其中 **91 点**绕数 0.5 以上（判据在折叠区不可信） |
| 广义绕数 w<0.5 | **746** | 对翻面/自交/开放边界稳健 |
| 封底 + 射线奇偶（独立实现） | **749** | 与绕数差 3 点 |

两个**互不依赖**的方法一致 → 746 是可信的；法向判据的 91 点差异**如实并记**
（`input_qc.outside_by_face_normal`），不掩盖 Occlusion 的翻面问题。

> **数字更正（J.1 提交 `8ddf42d` 修复绕向 bug 后重算）**：本节最初写的是
> "法向判 1128 点 / 差 450 点"，那是在 `refine_max_edge` 一组分裂组合把子三角形
> **绕反**（面积守恒但 37.6% 子面翻向）的情况下算出来的 —— 顶点法向被抵消成切向，
> **是测量侧的 bug 放大了差异**。修好后：法向判 **811** 点、差 **91** 点、
> `face_flipped_at_closest` 从 561 降到 **101**。**绕数/射线奇偶那两个数（746/749）
> 与距离量（t_closest/t_ray）不受影响**（它们只用面，不用顶点法向），结论不变。
> 同时新增面积加权指标：`flipped_area_ratio = 5.26%`（与面计数 5.28% 一致）。

## 4. 区域分账 + 冲突归因

区域：`anatomical_regions`（近中/远中/颊/舌按患者自己的 `AxisMesial`/`AxisBuccal`）
∪ 颈缘带（到颈环距离 < 1.0mm），颈缘优先。

归因**用几何 clearance**（不是区域标签）：把外表面点沿外法向推 `deficit` 后，
检查与邻牙/对颌 patch 的带符号距离是否仍 ≥ 目标间隙 + 余量（0.02mm）。
→ `REPAIRABLE_THIN` / `CONTACT_THICKNESS_CONFLICT` / `OCCLUSION_THICKNESS_CONFLICT` / `CERVICAL_THIN`。

负壁厚（内表面穿出外表面）**单独记账**，不混进四类：它不是"薄"，是覆盖率失败。

## 6. 测量机械的验证（4 个真实 bug，全部当场抓住）

这一节比结果更重要 —— 这些数字之所以能用，是因为**每个原语都与独立实现对过账**：

| # | bug | 症状 | 抓法 |
|---|---|---|---|
| 1 | `_point_tri_closest` 重心判据取错边函数 | 7% 三角形返回**面外**投影点 → 距离偏小（最大 24mm） | 对 `trimesh.triangles.closest_point` 与 `contact.closest_point_on_triangle` 双向对账（现 max 偏差 8.9e-16 / 5e-5） |
| 2 | 候选面只取质心 kNN | 真最近面质心排第 **127** 近 → 距离偏 0.35mm | 对 `NeighborPatch` + 暴力法对账；加顶点采样 + 关联面扩张；再加**保形细分**（最长边 0.35mm）后 0 偏差 |
| 3 | 细分非保形 + 一组分裂组合写错 | T-junction 造出 5040 条假边界边；面积掉 4% | 面积守恒守卫（写进函数，超 1e-9 相对误差直接抛错）+ 边界边计数 |
| 4 | 自交检测用"整块三角形投影"当区间 | 干净 H.1 假报 1887 对 | 改成"与对方平面的**交线段**区间重叠"（Möller），干净网格归零，合成三态（相交/分离/平行）单测 |

另外两条来自用户规格的要求也落实为代码：内外判定用绕数（双法独立一致）、
`t_ray` 用精确射线求交（法向无关，翻面不会让射线提前终止 —— 早期用符号距离场
步进时，咬合区一半采样点的 `t_ray` 被伪终止污染）。

单测：`tests/unit/geometry/test_thickness_v1.py`（17 条，含上述全部回归）。

## 7. 已知项 / 边界

* **状态语义**：本次 `status=FAILED` 来自**输入 QC**（376 自交 + `max_self_intersections=0`），
  测量本身有效、表格照出。FAILED 是"输入不可接受"，不是"没测出来"。
* **绕数边界带**（565 点）：开放壳的开口附近绕数 → 0.5，内外不可分，单列 flag=5。
* **独立复核的封底平面**会切过非平面颈缘：开口带附近两种判据都可疑，
  两个数并列给出、不取其一（746 vs 749）。
* **颈缘刀口带**（310 点，d_margin<0.1mm）不参与薄判定，单列计数；
  `boundary_safety_mm=0.6` 内的 1452 点记 flag=4。
* **冲突归因的推进方向**用最近面法向：翻面处该方向本身可疑 ——
  归因是**启发式**，Repair 提交里必须用"重解后复测"决定接受与否。
* 单病例验收，**不能**代表总体；下一步需要新 cohort 上做同样口径的批量审计。

## 8. 下一步（第二提交：Thickness Repair）

只动 `FREE_REPAIRABLE`，且沿用已验证的架构：

```
deficit = T − t，仅自由外表面
    ↓ 几何 target（沿外法向推）
local-band Laplacian（颈缘/接触核/咬合面锁定）
    ↓ line search
接受条件 = 厚度改善 AND Contact 不恶化 AND Occlusion 不重现穿透
           AND Margin/Intaglio 位移 = 0 AND 翻面/自交不恶化
```

**前置**：本题的负壁厚（覆盖率失败）不是 Repair 能修的 —— 外表面必须回到
"intaglio + MinThickness 驱动"的生成方式（即用户路线图里的
**Outer + Intaglio 共享 cervical boundary**）；而 376 处自交要先归因到
I.2/Occlusion 的哪一步（本次已定位到两个阶段各自的贡献：206 / +170）。

产物：`数据/crown_outer_results/occlusion_v1_case/thickness_audit_report.json` +
