# WelooAI牙冠自动设计 1.0 工作区

更新：2026-10-10。入口 http://127.0.0.1:8010/ ，选择“牙冠设计 · 1.0”。

定位：单冠初稿生成、设计师编辑、内冠布尔、几何检查与导出。自动化不可靠时转人工。
这是可操作的工程工作区；不是已经完成临床/加工验收的全自动产品。

## 操作流程

1. 创建病例，上传工作颌、对颌。支持 STL 和可解码的 HPS DCM；3Shape ZIP 使用现有导入面板。加密扫描仍需可读 STL。上下颌相对位姿须确认，上传不等于咬合配准。
2. 选择 FDI。传统定位没有可靠独立锚点时返回 REVIEW_REQUIRED。可开启带编号虚线牙弓，通过手柄平移、数值旋转和调整弓宽/弓深，再在实际扫描上点击基牙。点击槽位只是辅助位置，不是自动牙位确认。可采用已有凹谷测地线分区，也可用半径 ROI；两者都需检查污染。独立 Prep/Abutment 文件可直接上传。
3. 导入牙冠外形模板。没有模板的牙位可预览现有 32 牙位裁切候选，设计师确认后采用。候选未标注 CEJ，不应自动当作解剖真值。采用时转换为局部近中/咬合坐标，咬合方向 +Z。原始完整牙体仍仅作参考。
4. 创建任务。开放边界检测只适用于可信独立基牙；ROI 切口不是真实 Margin。可沿颈缘设置粗点，生成周期三次样条、投影至实际三角面得到候选。人工检查后保存。拖动已有点会吸附到基牙；Shift 点击删除；点选再点击表面可替换。绘制、替换、删除、候选生成支持撤销/重做。
5. 求解插入轴，或输入向量。可显示方向手柄与基于法向的倒凹着色，拖动箭头端点修改方向。颜色只是局部法向判据，求解器的倒凹面积/深度报告另行显示。确认方向写入修订。
6. 生成模板初稿。初始放置沿插入轴定位，并按 Margin 颈部包围尺寸拟合模板足迹；需检查旋转、冠高、邻接和咬合。也保留对应点 Kabsch 配准和 RBF 形变入口。
7. 打开冠体微调：手柄移动/旋转/缩放；数值等比例与三方向缩放；笔刷加/减材料、平滑、局部移动。局部移动使用指定三方向位移，在所画区域生效。沿真实三维 Margin 高度域以上 0.4mm 内固定，随后 1.2mm 平滑过渡。保存真实修改网格，禁止新增检测到的严重自交和翻面。坐标方向可绕插入轴调整，应确认 X 手柄与近远中对齐。
8. 选择机轴数，确认粘接间隙及起始距离，以方向 Blockout/Gap 和 manifold3d 布尔构造冠体，再重建共享三维颈缘。当前边缘延伸和边缘间隙须确认为零，自动整体补厚须关闭。Margin 改动后可选“保留现有冠形，重建颈部与内冠”；轴、基牙、模板变更需重新生成外冠。
9. 检查 STL 重读边缘误差、实际间隙、壁厚/薄区和工程拓扑报告。壁厚显示使用实际内面到外面的精确距离与法向射线采样，可高亮薄区，但不是解析全局最小壁厚证明。邻牙/对颌色图仍为无符号参考，不能代替有符号穿透审核；正式 Contact/Occlusion/MaterialProcess 标记 NOT_ASSESSED。
10. 导出最终 STL 或设计包。包包含输入、模板、当前产物、参数及修订和可用历史网格。已有病例通过“继续已有设计”重新打开。编辑外形、保存 Margin 或确认插入轴后，旧最终冠、内冠 cutter 和 QC 失效；重新生成后才能取得当前最终 STL。
