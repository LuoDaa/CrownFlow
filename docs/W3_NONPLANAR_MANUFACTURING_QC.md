# W3 — 三维 Margin 构造与工程几何审核

状态：ENGINEERING_ONLY / NOT_PRODUCTION_APPROVED。本次接入构造与测量，不代表完整制造验收。

## 实际构造

工作台 Finalize 使用已确认 Prep、Margin、Axis、Profile 修订。先检查 Margin 的轴向投影是否简单、单值闭环，禁止自交、扫描缺口自动补线。沿真实三维曲线构造连续高度域，裁取基牙就位面；不使用 Margin 拟合平面代替真实边界。

既有方向 Blockout 与变量 Gap Field 生成 cutter，manifold3d 求外冠减内冠。保留布尔冠体主体，裁出颈部过渡环，再复用 J.2 DP Seam 将内外冠连接到原始三维 Margin。共享边由同一组 Margin 顶点构成。导出 STL 后重新读取并检查共享边、双向采样边缘误差、拓扑及自交候选筛查。

`margin_band_mm` 是沿已确认轴的颈部重建过渡高度，必须大于零。当前只有共享刀口边缘，`margin_gap_mm`、`margin_extension_mm` 必须明确确认为零；非零配置会阻断，不能静默忽略。自动整体补厚尚未获联合 QC 验证，必须关闭。`voxel_pitch_mm` 为旧参数，当前精确布尔链不使用它；Blockout 的实际离散分辨率另有报告。材料名称不构成工艺验证。

## 保留冠形重建

`POST /api/designs/{id}/rebuild-cervical` 与 Finalize 使用相同的三个确认修订 ID 和输入摘要。只允许复用主体依赖仍可信的外冠；基牙、轴、模板或外冠文件变化均拒绝。Margin 改动可以重新构造颈部和内冠，原外冠文件不改写，并报告保留主体到原外冠的几何偏差。旧外冠缺少主体依赖记录时须重新生成一次。前端冠体编辑的颈缘保护也使用三维高度域，而非平均 Margin 平面。

## 四份交付

| 结果 | 实测内容 | 限制 |

| NonplanarMarginBuild | 曲线贴面距离、共享边、STL 重读双向边缘误差、保留主体偏差 | 无制造边缘误差阈值；共享刀口不是材料边缘工艺 |

| ManufacturingQC | 当前导出冠体拓扑、实际内面负拔模面积、方向阴影碰撞、上述审核 | 连续插入未认证；自交为候选筛查；Contact/Occlusion/MaterialProcess 标记 NOT_ASSESSED |
