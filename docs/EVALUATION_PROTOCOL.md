# 统一评估协议 v1（冠面 / 颈缘 / 内冠 / 邻接 / 对颌 / 网格质量）

**状态**：2026-10-11 冻结（阈值在看结果前注册，见表末）。
**适用**：`82404140632`（开发病例）、`82404090822`（第二病例验证集，配置冻结、只在失败后修改主线）。
**原则**：不同指标**禁止互相换算或相除比较**（如颈缘误差 ≠ 冠面 Chamfer）；每项指标单独报告。

## 0. 坐标与来源

- 全部计算在 **MODEL 坐标系**（病例自己的牙弓坐标系）内，单位 mm。
- 病例资产坐标关系必须来自**病例元数据**：`modelInfo.Margin ↔ constructionInfo.Margin` 的
  Kabsch（82404140632 残差中位 0.011mm）。禁止用待评估网格做 ICP 去"对齐"。
- **生成阶段不得读取 GT 牙冠**（P1 规则）；本协议中"评估区域"的定义允许使用 GT 的包围盒/曲线，
  因为它是**评估**口径且事先固定、逐病例记录。

## 1. 评估区域（全部以病例资产定义，事先固定）

| 区域 | 定义 |
|---|---|
| `bounds` | GT 设计冠 bbox ×1.05（只用于**限定评估范围**） |
| `body` 冠体 | GT 冠外表面顶点中，到最近 margin 点的**局部高度** ≥ 1.0mm |
| `margin_band` 颈缘带 | 同上，局部高度 < 1.0mm |
| `proximal` 近接区 | GT 冠外表面顶点中，到近中/远中邻牙 patch 的距离 < 2.0mm |
| `occlusal` 咬合区 | GT 冠外表面顶点中，到对颌牙弓的距离 < 2.0mm |
| `valid_tooth_surface` | 邻接/咬合区的**有效牙面**子集：该点的最近颌面点自身在牙面（到最近 margin 点局部高度 ≥ 2.0mm），排除牙龈/牙间乳头 |

## 2. 采样与计数规则

- 固定随机种子 `seed=0`；每个指标每侧最多采样 **10,000 点**；区域点数 < 10,000 时全取。
- 距离一律用最近距离原语 **`MeshDistanceExact`（严格证书 + 回退）**；快路径只允许在**已审计**的
  网格类别上启用（当前已审计：本两例的工作颌/GT 冠/patch；对抗样例见 `primitive_adversarial_v2.json`）。
- 体素类指标：体素边长 **0.25mm**，域 = `bounds`。
- 双向一律报告：`pred→GT` 与 `GT→pred`；HD95 = 两向合并点集的距离 p95。

## 3. 指标定义

| 指标 | 定义 | 报告项 |
|---|---|---|
| `surface` 冠面几何 | **参考=GT 冠外表面**。`gt→pred` 不做门（覆盖率方向，全 GT 外表面点）；`pred→gt` 只统计**距 GT 外表面 ≤1.5mm** 的 pred 点（其余为牙弓/背景面，记 `pred_far_frac`）。GT 基线行以"外表面子网格"作预测 | 双向中位/p95、HD95、`coverage_0.2mm`（GT 外表面点在 pred 0.2mm 内的占比）、`pred_far_frac` |
| `volume` 体积与覆盖 | `bounds` 内 pred<0 与 GT<0 体素 | volIoU、volBias |
| `margin` 颈缘 | 在 `margin_band` 内：pred 表面 → GT 表面距离 | 中位、p95 |
| `intaglio` 内冠 | pred 的**内表面**（法向朝内顶点）→ 预备体（工作颌）表面。**仅当对象含真实内表面时适用**（判据：`volume/凸包体积 < 0.5`，即壳结构）；实体/开放子网格记 `N/A` | 中位、p05、p95、CementGap 命中率（±0.03mm 带内占比） |
| `contact` 邻接 | patch（`valid_tooth_surface` 侧）→ pred 的**带符号间隙**（`sign(dot)·euclid`，|dot|/d<0.90 的歧义点剔除） | 最小、p05、穿透占比（< −0.05mm）、接触带覆盖率（GT 接触带 <0.2mm 的 90% 分位） |
| `antagonist` 对颌 | pred 的 `occlusal` 区表面 → 对颌牙弓 | 最小距离、穿透占比、`valid_tooth_surface` 限定下的最小距离 |
| `mesh_quality` 网格质量 | 导出前检查 | watertight、连通分量数、欧拉数、退化面数、翻面率（法向一致性）、自交（沿用项目既有 BVH 判据，本协议只记录是否已测） |

## 4. 预先注册的阈值（看结果前固定；由牙科工艺要求约束）

| 指标 | 阈值 | 依据 |
|---|---|---|
| `surface` p95 | ≤ 0.20mm | 项目接触/咬合 Gate 允许值 0.2mm；加工/就位一般要求 |
| `surface` 中位 | ≤ 0.10mm | 同上（更严的中位） |
| `volume` volIoU | ≥ 0.90；volBias ∈ [−0.05, +0.10] | 冠体不允许系统性膨胀/收缩 |
| `margin` p95 | ≤ 0.10mm | 颈缘贴合工艺要求（exocad 实际分区值 0.2mm 边缘区壁厚，误差应远小于此） |
| `intaglio` 命中率 | ≥ 95% 落在 CementGap ±0.03mm | 病例 `modelInfo.CementGapThickness`（本例 0.02mm；第二例 0.08mm） |
| `contact` 穿透 | < −0.05mm 的点占比 ≤ 1% | 扫描/设计噪声量级（实测 GT 自身 −0.04~−0.057mm） |
| `contact` 覆盖率 | ≥ 90%（0.2mm 内） | 接触区必须被 patch 覆盖才谈得上约束 |
| `antagonist` 穿透 | 有效牙面区内最小距离 ≥ −0.05mm | 同上 |
| `mesh_quality` | watertight=True、分量=1、翻面率 0、自交 0 | 项目既有 QC 不变量 |

> 阈值是**工程筛选线**，不是临床验收标准；不达标 ≠ 不可用，但必须记录失败类型与原因。

## 5. 复现与记录

- 每个被评估对象（GT 或某次生成）产出一份 `eval_*.json`：含病例、对象来源（STL 路径 + SHA256）、
  区域点数、全部指标、所用原语（`MeshDistanceExact`）、种子、脚本 SHA256。
- 生成侧的每次运行必须同时留：截取网格、归一化/变换矩阵、输入 SDF、预测 SDF、还原到 MODEL 的 STL
  （P0-5 已按此执行，见 `p0/p05/`）。
- 基线表：`p0/eval/baseline.md`（本协议下 GT 与既有预测的统一评分）。
- GT 基线行：以 GT 的**外表面子网格**作预测（于是 surface/margin/contact 自洽为 0/0/噪声）；
  该行的 `volume`/`mesh_quality` 记 `N/A`（开放子网格上无意义）。

## 6. 首次基线表（2026-10-11，两病例）与发现

完整表：`110.85:/data/luoda/oss_crown_research/p0/eval/baseline.md`。摘要（阈值判定）：

| 对象 | 冠面 p95 | cov@0.2 | volIoU | 颈缘 p95 | 邻接穿透 | 判定 |
|---|---:|---:|---:|---:|---|---|
| 82404140632 GT | 0.000 | 1.00 | N/A | 0.000 | 0.00/0.01 | 过（协议自校准） |
| 82404090822 GT | 0.000 | 1.00 | N/A | 0.000 | 0.05/0.04 | 过（邻接阈值待重标定，见下） |
| 全部 10 个 ToothCraft 预测（D0–D4） | 1.27–6.96 | 0.00–0.22 | 0.002–0.44 | 1.14–7.31 | 0–100% | **全部维度全部 FAIL** |

**发现（按纪律如实记录，不调阈值救结果）**：

1. **10 个预测无一通过任何一项阈值**；其中 2 个（`D4a_aligned_s16`、`D_single_damage_official`）
   的"冠面可归属点"为 **0**（预测表面整段落在 GT 冠 1.5mm 之外）→ 属完全失败模式，记 `nan`。
2. **阈值重标定项（唯一 GT 自身未过的线）**：第二病例 GT 在设计接触带上仍有 5%/4% 的点
   读数 < −0.05mm（第一例为 0%/1%），说明 −0.05mm/1% 这条线需在两例 GT 基线上重标定
   （例如按两例 GT 的 p99 定线）。重标定只看 GT 基线，不因任何模型结果松动。
3. `intaglio` 列对 ToothCraft 输出一律 `N/A`（实体、无内表面）；后续确定性 CAD 才有该指标。
4. 网格质量：4 个预测未过（非水密或分量 >1）——即"生成结果本身不可直接进下游"。
