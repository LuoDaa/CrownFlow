# WelooAI 传统几何 AutoFit：工程实现与验收边界

2026-10-10。依据桌面 `WelooAI_1_0_AutoFit_Implementation_Plan.md` 实施。当前为 `ENGINEERING_ONLY / NOT_PRODUCTION_APPROVED`。本记录区分实现、合成验收、真实病例失败证据，不能视为生产完成证明。

## 使用流程

1. 导入正确坐标与毫米单位的工作颌、对颌，以及独立天然基牙 Prep。确认真实三维 Margin、插入轴和设计配置。
2. 参数步骤填写并确认近邻目标间隙、静态咬合目标间隙；空值表示未确认，不默认为临床推荐值。材料名与材料工艺验收分开。
3. 在步骤三或四打开 AutoFit 输入面板，点选或输入近中、颊侧方向，确认单位。坐标不能直接沿用世界 XYZ。
4. 对近中、远中分别在原扫描上涂选真实邻牙面，人工检查污染和外向法向；也可明确标为 ABSENT 或 UNKNOWN。支持增选、擦除和重新确认。旧 FDI 相邻编号、半径 ROI 不自动升级为有效实例。
5. 复核静态上下颌变换并记录来源。支持已配准导出、外部人工配准、外部咬合扫描配准来源；本轮不自动完成配准。位姿人工确认不是算法认证。
6. 选择当前 FDI 的专业冠形库，生成独立放置候选。人工复核冠形、近中/颊侧朝向、颈缘候选后才能采纳初稿；此采纳不代表 W3 已通过。
7. 对当前可信外冠运行自动邻牙、自动咬合或全部适配。查看原冠/候选、线框叠加、逐阶段报告、输入诊断。未采纳时当前外冠不变。
8. 仅 PASS_ENGINEERING 的 AutoFit 候选可显式采纳；部分输入、冲突或未评估结果不能采纳。采纳形成 OUTER 修订并使旧 Final/Cutter/QC 失效，必须按 W3 完整重构。
9. 最终 QC 重新查询落盘的外冠表面，分别查看近中、远中、静态咬合、边缘、间隙、壁厚、拓扑和材料状态。之后再编辑冠体，旧报告失效。

## 实现

- 复用既有 PatientFrame、NeighborPatch、局部 Laplacian、DeformationGate、修订表与发布事务，没有新增另一套工程状态存储。
- `NeighborPatch.closest()` 使用完整 AABB 候选上的最近三角面查询。共享边等距面按稳定面 ID 选择，避免平移/旋转改变法向目标；分批计算，仍使用该三角面的法向。
- 水密且方向一致的实体用真实内外包含判定配合精确距离。开放邻牙面仅采用人工确认的局部外向法向；排除边界安全带、倾斜和法向不可靠样本，不声称拥有全局内外定义。
- 闭合工作台外冠不满足旧研究入口的开放颈环合同，因此适配器复用其查询、局部求解、回溯及硬门，不伪造颈环，也不直接调用要求开放网格的 I1/I2 包装入口。
- 固定原冠及审核域，先近邻、后静态咬合、再联合重测；颈部及禁改区硬锁，邻接核在咬合阶段受保护。三环过渡局部传播，回溯 α = 1、1/2、1/4、1/8、1/16。没有扫权重或放宽 Gate。
- 每个步检查目标改善、最大误差不恶化、原有效样本保留、累计翻面、几何门、位移上限。联合审核检查表面交叉不增加；预算超限明确阻断，不把未测当零。
- `penetration=max(0,-signed)` 与 `deficit=max(0,target-signed)` 分开。PASS_ENGINEERING 表示有效输入下的合法改善及 W3 工程构建，不代表完全达到目标、临床接触或制造认证。
- W3 预构冠真实运行方向 Blockout、间隙、布尔和共享三维 Margin Seam。采样薄区违反当前确认工程最小厚度时，不允许采纳。没有通过修改材料阈值绕过失败。
- 最终及预构冠 QC 查询真实落盘表面：有效/模糊样本、间隙、穿透、目标欠缺；封闭输入另测实体交叠体积。面相交采用 AABB 候选与现有三角形相交核，记录涉及面面积及交线长度。近平行/共面情况单列待审；涉及面面积不是实际重叠面积。
- 候选包含源网格、模板、方向 XML、修订和产物哈希。计算结束与显式采纳均执行版本/CAS 检查；拒绝与采纳通过 SQLite 写事务排序，ABA 修改后复原仍阻断旧结果。
- 历史候选及确认输入持久化，重开后恢复已确认方向和咬合矩阵；历史候选采纳仍需通过当前版本检查。

- 真实天然基牙完整端到端成功病例、临床接触目标与材料/工艺限值验收。

- 开放面共面交叠的完整分类、连续表面厚度最小值与连续插入路径证明；现有采样及局部符号只作为工程证据。
- 用户认证与病例授权尚未完成，确认字段不能视为经过认证的身份。

因此本轮交付是可运行、可追溯的 AutoFit 工程链路；完整方案的真实病例与生产验收仍未关闭。
