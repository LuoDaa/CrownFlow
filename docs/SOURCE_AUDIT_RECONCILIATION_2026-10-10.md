## 当前确认合同

- 手工保存 Margin 是显式确认；自动暂存曲线不是确认，须保存或采纳候选。
- 自动求轴不改变当前轴、当前产物或设计版本； `/axis` 才确认并产生 AXIS_ACCEPTED。
- Profile 修订、参数缓存和生效指针在同一事务保存；仅材料标签，不是工艺批准。
- Finalize 请求只允许 `expected_input_digest`、`margin_revision_id`、`axis_revision_id`、`profile_revision_id`。三个 ID 必须属于当前设计的生效确认修订，且内容与缓存一致。
- QC 与 FINAL 修订记录 consumed_revisions，FINAL 另记录输入 design_revision 和 digest。生成不能覆盖 Margin、Axis 或 Profile。
- Margin 或轴重新确认使旧外冠版本失效；需要重建。微调入口不再隐式替用户保存几何。
- 旧 API 几何请求不再兼容；旧设计没有确认指针时必须重新确认、重建。旧产物不自动取得新合同认可。
- SQLite 更新触发器递增设计版本；产物发布在 BEGIN IMMEDIATE 内检查快照版本和文件/字段摘要，并原子写入产物、QC和新摘要。候选修订不会增加生效设计版本。
