## 2. 实测几何

| 对象 | z 范围 | 体积 | 备注 |
|---|---|---|---|
| 基台 | 3.49–10.82 | 96.3 mm³ | 见下方剖面 |
| 真值冠 | 5.63–12.50 | 210.8 mm³ | 壳 |
| 对颌扫描 | 10.4–25.5 | — | 佐证咬合方向为 +Z |

基台沿 Z 的外环截面：

| z | r_mean | r_max |
|---|---|---|
| 4.2 – 5.2 | 1.21 – 1.25 | 1.37 – 1.44 |
| 5.7 | 1.67 | 2.17 |
| 6.2 | 2.41 | 3.16 |
| 6.7 – 9.7 | 2.71 – 2.93 | 3.14 – 3.31 |
| 10.2 | 1.68 | 2.58 |

即：颈部窄（种植体连接段，位于 Margin 以下）→ 外扩（emergence profile）
→ 近圆柱主体 → 咬合收缩。

**这个外扩段是本病例的关键特征**：它是**轴对称**凸起，相对**任何**就位轴都是倒凹，
换轴无法消除，只能靠 blockout。这一点是"不能用 '+Z 误差' 当验收判据"的原因之一，
详见 `INSERTION_AXIS.md` §6。

### 就位方向

| 量 | 值 |
|---|---|
| 基台侧壁法向独立拟合轴 | 偏离 +Z **12.9°**（拟合质量 eigenvalue ratio 0.105，7322 面） |
| 真实颈缘平面的法向 | 偏离 +Z **11.67°** —— 与基台轴线一致（边缘平面垂直于基台轴线） |
| 求解器输出 vs 拟合壁轴 | **2.27°** |
| 倒凹面积比（就位面内，沿最优轴） | **0.117**（+Z 为 0.328） |
| Margin 沿最优轴可见率 | **1.00** |
| 状态 | **`OK`** |

**该行为的判据被修正过。** 上一轮基于错误的 Margin（近似水平带，偏离 +Z 0.80°）
断言此病例必须报 `REVIEW_REQUIRED`，理由是"该基台有轴对称外扩 emergence profile"。
用正确的颈缘真值重算后该结论被推翻，记录在 `baseline.json` 的
`retracted_expectations`。详见 `docs/GT_MARGIN.md` §7。

**不要用"与 +Z 的夹角"作为该病例的验收目标** —— 基台自身就是斜的，
+Z 不是可从数据独立确认的真值。

## 4. Margin 真值：已修复

旧方法（"最低 0.4 mm 带"）只覆盖 16/24 方位角，是**残弧不是闭环**。
现已改用从真值冠提取的真实交界缝（`app/geometry/gt_margin.py`）。

```
闭环 True   简单 True   自交 0   方位角覆盖 1.000   周长 21.76 mm
genus 1（颈缘 + 螺丝通道口两条缝，靠语义选出颈缘）   置信度 0.99
```

FDI36 的冠 χ = 0（genus 1），所以"恰好一条缝"不是拓扑天然成立，
而是靠"投影是否包围 support 截面"选出来的（颈缘 1.000 vs 通道口 0.095）。
详见 `docs/GT_MARGIN.md`。
